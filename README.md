# WhoppahBot

A fun economy Discord bot with money, assets, trading, jobs, and more! Climb the corporate ladder and the
leaderboards to try and become the most powerful person in all of Whoppah World

---

## Features & Commands

### 🎮 Actions
- `cancel` — Cancel current action  
- `mine` — Start gold digging  
- `promotion` — Request a BK promotion  
- `status` — Check action status  
- `work` — Start a BK shift  

### 🛠️ Basic
- `bug` — Link to bug report form  
- `github` — Link to repo  
- `joke` — Tells a joke  
- `say` — Parrots what you say  
- `suggestion` — Link to suggestion form  
- `tutorial` — Get a quick tutorial  
- `whoppa` — Send a Whoppa gif  

### 🎲 Casino
- `coin` — Fair coin betting game  
- `dice` — Fair die betting game  

### 💰 Economy
- `balance` — Check your balance  
- `daily` — Claim a daily gift  
- `edgar` — Retrieve entity info  
- `exchange` — Trade assets  
- `leaderboard` — See the top users  
- `profile` — View your profile  
- `shop` — Open the BK menu  
- `transfer` — Send assets to another user  

### 📖 General
- `help` — Show this command list
